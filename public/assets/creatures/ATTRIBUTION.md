# Creature Mesh Attribution

The creature meshes in this directory are from Quaternius' **Ultimate Animated Animal Pack**.

- Source: https://quaternius.com/packs/ultimateanimatedanimals.html
- License: CC0 1.0 Universal
- License text: https://creativecommons.org/publicdomain/zero/1.0/
- Download source: Quaternius' public Google Drive folder linked from the pack page

Included source files:

- `wolf.gltf` — Wolf
- `fox.gltf` — Fox
- `deer.gltf` — Deer
- `stag.gltf` — Stag
- `bull.gltf` — Bull, used as the Devil base mesh with a red material treatment

The player's slime remains an original Three.js mesh and is not replaced by an external asset. The game maps the free meshes to the current creature roles so the on-screen creatures use authored meshes rather than the former primitive-only silhouettes.
